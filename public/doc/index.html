关于

我是谁

我是一名拥有 4 年以上经验的全栈开发工程师，擅长从零到一构建 Web 应用 —— 涵盖系统架构设计到生产环境部署的完整链路。我格外在意性能、开发体验，以及那些让软件用起来"对"的细节。

我的工作横跨整个技术栈：后端负责 API 与数据库模型设计，前端专注于响应式、可访问的交互界面，同时搭建将两端串联起来的 CI/CD 流水线。

我交付过数千日活用户规模的线上产品，既享受后端架构中的系统性思考，也热爱前端工程中对细节精雕细琢的过程。工作之余，我会撰写技术文章、参与开源项目，并用 CSS 和 JS 探索生成艺术。
