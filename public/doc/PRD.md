# 个人作品集网站 (Personal Portfolio) 产品需求文档 (PRD)

## 1. 产品概述与目标用户

### 1.1 产品概述
本项目旨在开发一个极简、现代的个人作品集网站（Personal Portfolio），作为展示个人专业技能、项目经验和职业背景的“数字名片”。该网站将以深色主题为主，结合流畅的交互动画，为访客提供沉浸式的浏览体验，从而提升个人品牌价值。

### 1.2 目标用户
* **招聘方 (HR/猎头)**：快速了解候选人的基本信息、技能栈和过往履历。
* **技术面试官/技术负责人**：深入查看项目源码（GitHub）、在线演示（Demo）以及技术实现细节。
* **潜在客户 (针对自由职业者)**：评估专业能力，查看过往成功案例，并获取联系方式。
* **同行开发者**：技术交流、开源项目合作。

---

## 2. 详细功能列表

### 2.1 首页 (Hero Section)
* **大标题与问候语**：引人注目的个性化问候（如 "Hi, I'm [Name], a [Role]"）。
* **个人简介**：1-2句话的简短定位，突出核心优势。
* **个人头像/3D形象**：高质量的专业头像或具有设计感的个人化身。
* **CTA按钮 (Call to Action)**：如“查看项目 (View Work)”和“下载简历 (Download Resume)”，引导用户滚动或操作。

### 2.2 关于我 (About Me)
* **详细介绍**：分段描述职业背景、技术热情和个人发展方向。
* **技能树/标签墙**：
  * 将技能分类展示（如：前端、后端、工具、设计等）。
  * 使用直观的进度条或徽章（Badges）展示熟练度。
* **教育与工作经历（可选扩展）**：以时间轴（Timeline）的形式展示核心履历。

### 2.3 项目展示 (Projects)
* **项目卡片网格**：响应式排列的项目列表。
* **卡片内容**：
  * **项目截图/封面**：高质量的项目预览图。
  * **项目名称**：清晰的项目标题。
  * **简短描述**：一两句话说明项目解决了什么问题。
  * **技术栈标签**：该项目使用的核心技术（如 React, Node.js, Tailwind）。
  * **操作链接**：包含“源码链接 (GitHub)”和“在线预览 (Live Demo)”的图标按钮。
* **交互效果**：鼠标悬浮（Hover）时卡片放大或显示详细信息遮罩层。

### 2.4 联系方式 (Contact)
* **社交媒体矩阵**：GitHub、LinkedIn、Twitter/X、个人博客等图标链接。
* **直接联系方式**：可一键复制的电子邮箱地址。
* **留言表单（可选扩展）**：包含姓名、邮箱、留言内容的简单表单，支持直接发送到个人邮箱。
* **页脚 (Footer)**：版权信息及网站构建年份。

## 3. 功能优先级 (MVP 与后续版本)

### 3.1 MVP 版本 (V1.0 - 核心展示)
* **P0（必须具备）**：首页展示、关于我（纯文本+技能标签）、项目展示（静态数据渲染卡片）、联系方式（纯链接）。
* **P0（必须具备）**：深色主题（强制深色）、基础的响应式布局（适配手机与PC）。
* **P1（高优先级）**：平滑滚动（Smooth Scrolling）、基础的页面进入淡入动画。

### 3.2 后续版本 (V2.0 - 体验升级)
* **P2（中优先级）**：主题切换（支持浅色/深色模式切换）。
* **P2（中优先级）**：多语言支持（i18n，如中英文切换）。
* **P2（中优先级）**：工作经历时间轴展示。
* **P3（低优先级）**：可交互的联系表单（接入 EmailJS 或类似服务）。
* **P3（低优先级）**：博客模块（集成 Markdown/MDX 渲染技术文章）。

## 4. 界面设计要求 (UI/UX)

* **设计风格**：极简主义（Minimalist）、现代感、高对比度。
* **色彩规范 (深色主题)**：
  * 背景色：深灰/纯黑（如 `#121212` 或 `#0F172A`）。
  * 主文本色：灰白（如 `#E2E8F0`），确保高可读性。
  * 强调色 (Accent Color)：选择一种亮色作为点缀（如荧光绿、电光蓝或紫色），用于按钮、链接和图标悬停。
* **排版 (Typography)**：
  * 标题字体：无衬线现代字体（如 Inter, Roboto, 或具有几何感的 Poppins）。
  * 保持充足的留白（Whitespace），避免信息拥挤。
* **交互与动画**：
  * **滚动动画**：使用平滑滚动导航到不同区块。
  * **视差/滚动揭示**：随着页面向下滚动，元素依次淡入（Fade-in up）。
  * **微交互**：按钮悬停变色/缩放，项目卡片悬浮时的阴影加深或图片轻微放大。
* **移动端适配**：
  * 采用移动端优先（Mobile-first）设计原则。
  * 导航栏在移动端折叠为汉堡菜单（Hamburger Menu）。
  * 项目卡片在手机端自动切换为单列布局。

## 5. 技术栈建议

为了保证性能、现代感以及开发效率，建议采用以下技术栈：

* **前端框架**：`Next.js` (React) 或 `Nuxt.js` (Vue)。
  * *理由*：支持静态站点生成（SSG），对 SEO 极度友好，首屏加载极快。
* **样式方案**：`Tailwind CSS`。
  * *理由*：极大地加速 UI 开发，内置优秀的深色模式支持和响应式断点。
* **动画库**：`Framer Motion` (React) 或 `GSAP`。
  * *理由*：轻松实现复杂的滚动揭示动画和丝滑的组件过渡效果。
* **图标库**：`Lucide Icons` 或 `React Icons`。
* **部署平台**：`Vercel` 或 `Netlify`。
  * *理由*：与 GitHub 深度集成，免费且支持自动化 CI/CD 部署。
* **数据管理**：初期可直接使用本地 JSON 文件或硬编码，后续若需博客功能可引入 `MDX`。

## 6. 非功能性需求

### 6.1 性能需求 (Performance)
* **加载速度**：首屏加载时间（LCP）应小于 1.5 秒。
* **图片优化**：所有项目截图和头像必须经过压缩，并使用现代格式（如 WebP），支持懒加载（Lazy Loading）。
* **跑分目标**：Google Lighthouse 性能、可访问性、SEO 评分均需达到 90+。

### 6.2 搜索引擎优化 (SEO)
* **Meta 标签**：配置完整的 Title, Description, Keywords。
* **Open Graph**：配置 OG 标签，确保在微信、Twitter、LinkedIn 等社交平台分享时能显示漂亮的预览图和标题。
* **语义化标签**：合理使用 `<header>`, `<main>`, `<section>`, `<footer>` 等 HTML5 语义化标签。

### 6.3 安全性 (Security)
* **HTTPS**：全站强制使用 HTTPS 加密（Vercel/Netlify 默认提供）。
* **防爬虫/防骚扰**：如果后续加入留言表单，需接入基础的防机器验证（如 Google reCAPTCHA 或 Turnstile），并在前端对邮箱地址进行适度混淆以防垃圾邮件爬虫。

### 6.4 可访问性 (Accessibility / a11y)
* **键盘导航**：确保用户可以使用 `Tab` 键浏览所有交互元素（链接、按钮）。
* **ARIA 标签**：为图标和非文本元素添加 `aria-label`。
* **色彩对比度**：确保文本与深色背景之间的对比度符合 WCAG AA 标准，保证阅读清晰。
